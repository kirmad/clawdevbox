Pre-release · MIT licensed · MCP-first

Agents for developers, on autopilot

ClawDevbox runs AI coding agents — GitHub Copilot CLI, Claude Code, Cursor — headlessly inside hidden pseudo-terminals, and wraps them in recipes, triggers, skills, durable memory, plugins and browser-based viewers. Every capability is an MCP tool, so the same surface works from a side terminal, an external agent, or a scheduled script.

What it gives you

Hidden agent runs

Spawn copilot, claude, or any TTY-driven CLI inside a node-pty (ConPTY on Windows) — no console window flashes. Each run gets an isolated workspace.

Live browser viewers

An HTTP/WebSocket server exposes view_urls. Watch a live xterm, type input, or render artifacts — design docs, PR reviews, code walkthroughs — right in the browser.

Self-evolving memory

Facts, lessons and wiki pages live in git-backed vaults. Agents recall before they re-derive, record what they learn, and vote to keep the knowledge base honest.

Proactive triggers

Cron-scheduled or webhook-fired scripts watch PRs, work items, or metrics and wake an agent when something needs attention — no human in the loop required.

How it works, in one line

The sidecar does not run an agent loop — your CLI does. ClawDevbox keeps a single SQLite kernel consistent, exposes it as an MCP server, and wakes agents up when triggers demand it.

Trigger fires → Recipe selected → Agent CLI spawned in a hidden PTY → Calls MCP tools → Publishes artifacts + memory
