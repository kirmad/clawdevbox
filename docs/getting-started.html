Introduction

Getting Started

Install ClawDevbox, initialize it once, start the MCP server, and point your agent CLI at it. In a few minutes you'll have hidden agent runs, a live browser viewer, and the full recipe / skill / trigger / memory surface.

Pre-release

The reference implementation ships as a working sample. APIs and on-disk formats are not stable yet — pin a commit if you build on top of it.

Prerequisites

  • Node.js 18+ — the MCP server runs on Node with node-pty (ConPTY on Windows).
  • An agent CLI you install yourself — GitHub copilot, claude (Claude Code), Cursor, or any TTY-driven CLI that accepts an MCP config. ClawDevbox does not bundle the agent.
  • git — for cloning the repo and for git-based plugin / memory-vault sync.
  • A modern browser — for the live terminal and artifact viewers.

Install & set up

Clone the repository and install the MCP server's dependencies. The Playwright Chromium download powers the browser verification scripts.

git clone https://github.com/kirmad/clawdevbox
cd clawdevbox/mcp-server
npm install
npx playwright install chromium

Initialize with clawdevbox init

clawdevbox init is the single setup command. It asks for an install scope:

ScopeWhere config livesWhen to use
Global (recommended)<globalDir>/config.json (default ~/.clawdevbox/config.json); plugins under <globalDir>/plugins/One install per user. Every project sees the same MCP server, tunnel, and plugin set.
Project-specific<projectDir>/.clawdevbox/config.jsonLegacy path. A repo needs its own port / token / tunnel.
 
# Interactive
clawdevbox init

# Non-interactive, global, with a plugin from git
clawdevbox init --scope global --plugin git+https://example.com/some-plugin.git

resolveConfig merges both layers when present (project > global > defaults). Environment variables and CLI flags override anything on disk.

Running the server

After init, there are three ways to run the MCP server:

CommandModeNotes
clawdevbox mcpStdio MCPWired up by your agent (Claude Code, Copilot, …) as a stdio server.
clawdevbox startHTTP MCP (foreground)Runs until you press Ctrl+C.
clawdevbox start --serviceHTTP MCP (background)Detaches and registers OS auto-start at login. Idempotent.
 
clawdevbox start --service     # install + start now (idempotent)
clawdevbox status              # is it running? auto-start installed?
clawdevbox stop                # halt; auto-start remains registered
clawdevbox uninstall-service   # stop + remove auto-start

The background service uses the platform's native scheduler for "always running across reboots" semantics:

  • Windows — Task Scheduler (schtasks)
  • macOS — LaunchAgents (launchctl)
  • Linux — systemd-user (systemctl --user)

PID and port are recorded in <globalDir>/service.json so stop always finds the running instance. Only one global instance is supported per user account.

Wire up your agent

At boot the sidecar writes an MCP config the agent CLI can consume. The CLI is spawned with that config so every ClawDevbox tool becomes visible:

{
  "mcpServers": {
    "clawdevbox": {
      "type": "streamable-http",
      "uri": "http://localhost:5201/mcp",
      "headers": { "Authorization": "Bearer <per-launch-secret>" }
    }
  }
}

Tools are exposed through a meta-tool gateway — list_tools → learn_tool → run_tool — so agents only pay schema tokens for the tools they actually use. See the MCP Tools Reference.

Demos you can run

From mcp-server/, each demo opens a headed Chromium so you can watch it live:

# Live terminal viewer over a hidden node-pty
npx tsx demo-terminal-view.mjs

# Interactive agent CLI inside the hidden pty, viewed in the browser
npx tsx demo-agency-interactive.mjs

# Code walkthrough overlay (floating panel on top of the diff)
npx tsx demo-walkthrough.mjs

# Full PR review viewer with hierarchical file tree + full-file diff
npx tsx demo-pr-review.mjs

Verify end-to-end

# Agent CLI ↔ MCP round-trip via recipe.run
node e2e-test.mjs

# Locked-size xterm survives browser resize without misalignment
npx tsx verify-agency-alignment.mjs

# All three built-in renderers tested in headless Chromium with screenshots
npx tsx verify-artifacts.mjs
